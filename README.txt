NOVA PROFILES
=============

A documentação atual fica em README.md:
https://github.com/VitorManuel01/NovaProfiles

Instalação pelo código-fonte:
1. Use Windows x64 e CPython 3.11 a 3.14 x64.
2. Execute INSTALAR.cmd.
3. Execute EXECUTAR.cmd.

IMPORTANTE: feche o GameSir Connect e pare o serviço antigo
GameSirAutoProfile antes de aplicar mapeamentos HID.

Para diagnóstico, execute EXECUTAR_DEBUG.cmd.
Para build, consulte docs\BUILDING.md e execute BUILD_EXE.cmd.
